## 一、不确定性治理

1. LLM 输出必须依赖数据库/知识库检索结果，禁止凭空生成金额、时间、政策、记录、结论；
2. RAG 检索 score<0.6 判定无匹配，直接兜底回答，禁止强行回答；
3. LLM 输出 confidence<0.7 禁止直接回复用户，触发兜底或转人工；
4. 意图识别 confidence<0.6 记 uncertain 不阻断流程，但落记录；
5. 关键业务字段（金额、政策、逾期天数）开启结构化输出 + 字段强校验，校验不过丢弃重生成。

## 二、降级总原则与兜底分级

LLM 超时、报错、检索为空，全部走业务兜底，禁止抛异常给终端客户。分级如下：

| 层级 | 触发 | 兜底动作 |
|---|---|---|
| L1 LLM 调用失败 | 超时/熔断/报错 | 返回预设兜底话术（RuleBasedScriptEngine 本地决策树） |
| L2 知识库检索无果 | score<0.6 或为空 | 使用标准 FAQ 兜底，不自由作答 |
| L3 合规拦截触发 | 前置/后置校验不通过 | 返回合规兜底话术，记告警，违规内容不向下游传递 |

兜底话术统一在 rag-service 标准答案库维护，禁止硬编码在业务代码（详见 step1/03 兜底话术表）。

## 三、容错与降级矩阵

| 依赖 | 熔断/失败阈值 | 降级方案 | 依据 |
|---|---|---|---|
| 大模型 API | 连续 3 次失败 或 P95>800ms | 切换 RuleBasedScriptEngine 本地催收话术决策树 | openspec 04/06 |
| ASR | 连续 3 次置信度<0.5 | 播报"抱歉没听清，请您再说一遍"；累计 5 次结束通话 | step1/01 |
| TTS | 合成失败 | 播放预设兜底提示音，结束通话 | step1/01 |
| RAG 检索 | 服务超时/报错 | 降级为静态标准话术库，记录降级日志 | openspec 04 |
| RAG 置信度 | score<0.6 | 返回空 + 标记"知识库无匹配"，调用方走兜底 | step1/01 |
| LLM 置信度 | confidence<0.7 | 禁止直接回复，触发转人工 | step1/01 |
| 呼叫中心 | 接口超时/报错 | 任务标记待重试，计入下一轮调度 | step1/01 |
| 质检服务 | 响应>3s | 不中断通话，降级为事后离线质检 | openspec 06 |
| 数据中台同步 | 失败 | 自动重试 3 次，仍失败告警，数据不丢失 | openspec 06 |
| 策略回流 | 失败 | 自动回滚，保障业务规则稳定 | openspec 06 |
| 对话轮次 | 达 13 轮 | AI 主动引导结束；达 15 轮强制转人工 | step1/01 |
| 话术重复 | 3 轮内完全相同话术 | 立即抛异常转人工 | step1/01 |
| 并发呼叫 | >50 路 | asyncio.Semaphore(50) + 令牌桶，超额排队 | step1/01 |

## 四、熔断与重试参数

- 服务间同步调用：5s 超时 + 3 次指数退避（1s/2s/4s）；
- LLM 熔断：窗口期内连续 3 次失败触发熔断，窗口期内停止调用大模型、走固定兜底；
- ASR 连续 3 次置信度<0.5 走兜底，累计 5 次结束通话；用户静默 10 秒引导、20 秒结束；
- 数据中台同步失败自动重试 3 次，仍失败告警，数据不丢失；
- 策略回流失败自动回滚，保障业务规则稳定。

## 五、通话轮次与并发约束

- 单通话最大 15 轮，第 13 轮触发关键要素判断分支、AI 主动引导结束；
- 3 轮内完全相同话术立即抛异常转人工；
- 并发上限 50 路（asyncio.Semaphore(50) + 令牌桶），超额排队；
- 外呼时段 08:00–21:00，非时段入口拦截返回 A1001。

## 六、监控告警

高危事件必须告警记录（对齐 openspec/specs/06 强制4）：

- LLM 批量失败、高频超时、熔断触发；
- 合规拦截触发（前置/后置）；
- 异常访问、SQL 高危操作；
- 接口报错暴涨、并发触达上限；
- 数据中台同步/策略回流失败。

所有超时、熔断、降级事件完整埋点日志（入参、报错堆栈、请求 ID、会话 ID、时间戳、trace_id），送入数据中台并支持告警与问题复盘。
