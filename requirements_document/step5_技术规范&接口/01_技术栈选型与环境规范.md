## 一、选型原则

| # | 原则 | 执行标准 |
|---|---|---|
| 1 | 宪法优先 | 不得违背 openspec/specs 硬性规则；版本锁定、环境分离、限流为硬约束 |
| 2 | 版本锁定 | 分级锁定：core 依赖（FastAPI/SQLAlchemy/Alembic/asyncpg/LangGraph/pymilvus 等）经 pip-tools 生成 requirements.lock（含哈希）；教学/工具类依赖（文档解析、OCR、测试工具等）降为 `>=` 下限约束、允许小版本浮动（见 §2.10） |
| 3 | 异步优先 | I/O 密集场景（DB/HTTP/Redis/Milvus/LLM/ASR/TTS）一律 async/await；禁用 time.sleep() |
| 4 | 国产可用 | 大模型优先阿里云 DashScope；ASR/TTS 用阿里云 NLS；呼叫中心用阿里云 CCC |
| 5 | 教学友好 | 选型倾向文档丰富、社区活跃、API 直观的技术 |
| 6 | docker-compose 可起 | 所有组件在 docker-compose 单机环境可一键拉起，prod 可平滑迁移 k8s |

## 三、第三方服务集成

### 3.1 大模型（DashScope qwen-plus）

| 维度 | 说明 |
|---|---|
| Provider | 阿里云 DashScope，模型 qwen-plus |
| 接入方式 | dashscope SDK；OpenAI 协议兼容，可切换 OpenAI/智谱/DeepSeek |
| 认证 | LLM_API_KEY（.env 注入，不入 Git；生产走 docker secrets） |
| 调用规范 | 推理参数按场景分层注入：评测/回归集 temperature=0.1、top_p=0.9、seed=42（固定，仅评测分支）；生产对话生成 temperature 默认 0.3（可配置 0.1~0.5）、seed 不固定（见 step5/03 §6.2）；强制 response_format=json_object；Schema 拆 reasoning + answer |
| 限速 | 5s 超时 + 3 次指数退避（1s/2s/4s）；asyncio.Semaphore 并发控制 |
| 降级 | 连续 3 次失败或 P95>800ms → pybreaker 熔断 → 切 RuleBasedScriptEngine |
| 兜底错误码 | A1010（LLM 摘要失败/置信度不足转人工，P1-12 厘清：LLM 异常统一走 A1010，A1013 专用于语音链路） |

### 3.2 ASR（阿里云 NLS 实时 WebSocket）

| 维度 | 说明 |
|---|---|

| 接入方式 | WebSocket 流式，`common/speech/asr_provider.py` |
| 认证 | ASR_APP_KEY / ASR_ACCESS_TOKEN（.env） |

| 兜底错误码 | A1005（ASR 连续失败）、A1006（静默超时） |


## 七、命名规范

| 对象 | 规范 | 示例 |
|---|---|---|
| Python 模块/文件 | snake_case | `call_dispatch.py` |
| 类 | PascalCase | `LLMProvider`、`QcOfflineService` |
| 函数/变量 | snake_case | `async def make_call()` |
| 常量 | UPPER_SNAKE | `MAX_DIALOG_TURNS = 15` |
| 数据库表 | snake_case 复数 | `call_records`、`dialog_turns` |
| 数据库字段 | snake_case | `session_id`、`create_time` |
| 数据中台分层表 | `<层>_<主题>_<表>` | `dwd_call_records`、`dws_agent_daily_summary` |
| API 路径 | 复数名词小写，kebab-case | `/qc/records`、`/kb/documents` |
| 错误码 | `<域><4位序号>` | `A1001`、`B0010` |
| 环境变量 | UPPER_SNAKE，前缀分模块 | `LLM_API_KEY`、`ASR_PROVIDER` |
| Git 分支 | `feature/<scope>-<short>` | `feature/qc-offline-job` |

时间一律 ISO 8601 + 带时区（Asia/Shanghai），如 `2026-08-19T10:00:00+08:00`。
