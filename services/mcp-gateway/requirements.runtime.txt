# mcp-gateway Docker 运行时增量依赖（全局 requirements.lock 之外）
# mcp SDK pin 1.x 稳定线：FastMCP 高层 API 成熟，支持 streamable-http / sse transport；
# 2.x 为重写版（API 重构 + mcp-types 独立包），成熟度风险见 change design.md Risks。
# 注意：mcp 1.x 要求 pydantic>=2.11 / uvicorn>=0.31 / httpx>=0.27 / pydantic-settings>=2.5，
