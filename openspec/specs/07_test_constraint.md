# AI项目自动化测试、回归、幻觉治理、上线准入规范

【强制1】所有新增AI业务、话术逻辑、研判规则、RAG逻辑，必须配套LLM回归测试用例。
【强制2】所有合规红线场景必须自动化拦截测试通过、拦截率 100%，任一红线用例未拦截即阻断发布，禁止人工兜底上线。
【强制3】AI输出必须可稳定复现、可对比、可打分，禁止随机波动、不稳定输出。
【强制4】幻觉高危场景专项测试：金额计算、政策解读、逾期天数、征信结论、法律判定、投诉定性。
【强制5】上线准入必须全量通过：合规测试、幻觉测试、降级熔断测试、并发测试、稳定性测试。
【强制6】所有线上问题、幻觉案例、违规输出，必须沉淀为固定回归用例，防止二次复发。
【强制7】AI打分、研判、质检结果必须具备一致性，相同入参输出相同结果，禁止随机偏差。
【强制8】核心业务模块测试覆盖率≥85%，CI 合并门禁含 ruff、bandit、mypy、覆盖率检查，未通过禁止合并。
【AI开发硬性指令】未通过测试规范的代码禁止合并、禁止上线、禁止归档。
