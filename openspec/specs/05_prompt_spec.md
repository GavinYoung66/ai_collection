# LLM Prompt编写与结构化输出强制开发规范

【强制1】所有催收业务场景必须启用结构化JSON输出，禁止自由文本、无格式乱输出。
【强制2】所有Prompt统一配置化管理，yml/常量文件统一维护，禁止业务代码硬编码Prompt。
【强制3】标准Prompt结构必须包含：角色定位、任务目标、输入约束、输出JSON Schema、禁止行为、兜底规则、枚举限定。
【强制4】所有AI返回结果必须做：JSON解析校验、字段必填校验、类型校验、枚举值校验、长度校验。
【强制5】质检、打分、标签、分类、投诉研判、风险判定场景，严格固定枚举输出，禁止自定义文字结果。
【强制6】动态业务变量（金额、姓名、日期、账单数据）禁止拼接Prompt明文，必须参数注入。
【AI开发硬性指令】无Schema、无校验、无约束的Prompt开发一律打回重写，杜绝幻觉与不稳定性。
