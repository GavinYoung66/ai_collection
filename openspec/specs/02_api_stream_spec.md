# 后端接口 + AI流式输出强制规范（全站统一，无例外）

【强制1】全站接口统一固定返回结构体：{"code":"0","message":str,"data":any|null,"trace_id":str}，code 为字符串、"0"表示成功，禁止自定义返回格式。
【强制2】成功 code="0"；业务错误使用 A1xxx~A7xxx+B 错误码全集（详见 step6/01），子系统新增码须经评审收录、禁止私自编号；HTTP 状态码：成功与业务错误统一 200、系统异常 5xx，均封装为统一包。
【强制3】所有异常禁止原生堆栈外抛，必须全局捕获、封装业务提示、隐藏技术细节。
【强制4】所有AI对话、实时外呼、流式问答、动态文本输出必须SSE分片流式输出，禁止一次性大包返回。
【强制5】流式输出固定四标识：start分片开始、content内容分片、end结束、error异常终止，字段不可缺失。
【强制6】所有接口必须做：非空校验、长度校验、非法字符校验、参数类型校验、业务规则校验。
【强制7】所有AI接口全量埋点：会话ID、用户ID、Prompt入参、模型返回、耗时、模型版本、拦截状态。
【AI开发硬性指令】所有AI相关接口必须流式结构+日志埋点，缺失任意项视为不通过。
