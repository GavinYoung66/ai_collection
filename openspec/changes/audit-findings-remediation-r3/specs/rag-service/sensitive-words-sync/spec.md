# Spec Delta

## ADDED Requirements

### Requirement: 敏感词资源保护与字典单源

敏感词库查询与字典下发端点 MUST 要求鉴权或仅限内部网络访问，并 MUST 配置限流。字典文件路径 MUST 由单一常量/配置定义，MUST NOT 在多处字面重复定义导致漂移。

#### Scenario: 匿名读取词库被拒

- **WHEN** 未认证调用方请求敏感词库或 `current.dict`
- **THEN** 返回 401/403 或按内部隔离策略不可达，不返回全量防护词表

#### Scenario: 词库访问受限流约束

- **WHEN** 已授权调用方在短时间内高频拉取词库
- **THEN** 请求受既有固定窗口限流约束，不出现无限量下载

#### Scenario: 字典路径单源

- **WHEN** 修改字典文件路径配置
- **THEN** 查询端点与同步任务读取到同一路径，无需同时修改两处字面量
